    Select proposal

    Default link validity: 30 days. You can revoke a link at any time. The raw token is shown once — copy it immediately.

    PDF exports

    From frozen versions

    Each published version above can be exported as a PDF from the Studio (open the proposal → Print / Save as PDF), or requested by the customer from the portal — those requests appear under Activity. No PDF bytes are stored on this server yet; R2 storage is a planned next step.
